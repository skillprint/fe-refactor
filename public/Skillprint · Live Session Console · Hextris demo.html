What happens when you press Start

  1. PlayHextris opens beside the live scores. Click the board to start and steer with the arrow keys.
  2. CaptureOne frame a second goes to the scoring API in batches of five.
  3. ScoreFlow and skill scores fill in as each batch is analysed, usually within a minute.
  4. AdaptWhen the API changes the creation speed, the new value is sent straight into the game.
