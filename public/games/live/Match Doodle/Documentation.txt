===============
Match Doodle Event List
===============
LEVEL_START => Player start the level
	- LEVEL_START (event)
	- 0 (level)
	- 0 (objectives)
---------------
DRAG/DROP => Player drag/drop the object
	- PICKUP/DROP (event)
	- 1/2/.../40 (object_id)
	- 0 (time)
---------------
MATCH => Player puts object on table
	- MATCH/UNMATCH (event)
	- 0 (time)
	- 0 (object_done) // this is the object id player dropped
---------------
LEVEL_COMPLETE => Player finish the level
	- LEVEL_COMPLETE (event)
	- 0 (level)
	- 0 (time)
---------------
LEVEL_QUIT => Player stop the game
	- LEVEL_QUIT (event)
	- 0 (level)
---------------
LEVEL_RESTART => Player re-starts the game
	- LEVEL_RESTART (event)
	- 0 (level)
---------------
OBJECTIVES_CHANGED => The Skillprint `pairs` knob changed the pairs in the level in play
	- OBJECTIVES_CHANGED (event)
	- 0 (level)
	- 0 (objectives)
---------------
Notes: `time` is the elapsed time in the level in milliseconds (the clock counts up; there is no time limit). `object_done` on MATCH/UNMATCH is the number of pairs found so far in the level. LEVEL_START `objectives` is the number of pairs in the level.
