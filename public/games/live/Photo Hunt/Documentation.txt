LEVEL_START => Player start the level
	- LEVEL_START (event)
	- 1 (level)
---------------
Tap => Everytime player tap the screen
	- TAP (event)
	- true/false (condition)
	- 1 (difficulty) - 0,1,2,3 * 0=missed tap
	- 0 (guess)
	- 0 (time)
	- 0 (penalty_ms) * only on a miss when the Skillprint missPenaltySeconds knob is above 0
---------------
TILT => Too many wrong taps within one second; taps are locked for a second
	- TILT (event)
	- 1 (level)
	- 0 (guess)
	- 0 (time)
---------------
LEVEL_FAILED => Player failed the level
	- LEVEL_FAILED (event)
	- 1 (level)
	- 0 (guess)
	- 0 (time)
---------------
LEVEL_COMPLETE => Player finish the level
	- LEVEL_COMPLETE (event)
	- 1 (level)
	- 0 (guess)
	- 0 (time)
---------------
LEVEL_RESTART => Player restart the level
	- LEVEL_RESTART (event)
	- 1 (level)
---------------
LEVEL_QUIT => Player quit from the level
	- LEVEL_QUIT (event)
	- 1 (level)
---------------
ALL_LEVELS_COMPLETED => All levels in the game has been completed
	- ALL_LEVELS_COMPLETED
---------------
Notes: `time` is the time left on the puzzle's clock in milliseconds (it counts down). `guess` is the number of differences found so far. `difficulty` comes from puzzles.xml (1 for every difference today; 0 = a missed tap).
