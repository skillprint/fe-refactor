===============
Trails WebAR Event List
===============
Messages the game posts to the host page (window.parent) when embedded.

LEVEL_START => Player starts a numbered level or an endless wave
	- LEVEL_START (gameEvent)
	- level (number: level 1-44, or the wave number in the endless mode)
	- group (numbered levels only: the level group key)
	- mood / nodes / dimension / rotate / arrow (endless waves only: the wave setup)
---------------
LEVEL_COMPLETE => Player connects every node of a level or wave
	- LEVEL_COMPLETE (gameEvent)
	- level, actualTime, idealTime, errors, pathEfficiency (ideal path / path travelled)
	- score, timeRatio (endless waves only)
---------------
gameState => Progress inside a level or wave
	- score (nodes connected so far; waves completed once a wave ends)
	- isGameOver (false)
---------------
GAME_COMPLETE => A numbered level is finished, or the player leaves an endless run from its Menu
	- score (nodes connected for a level; waves completed for an endless run)
	- errors, actualTime, idealTime (levels) / mood (endless)
---------------
screenshot => Periodic capture while playing (every 2.5 s)
	- dataUrl (JPEG data URL)
---------------
skillprint_keydown => Keys 1-9 pressed inside the game, for the keyboard adjustment tester
	- key
---------------
Incoming: ADJUST_GAME with data { parameterName, parameterValue } (see parameters.json).
In the endless mode an adjustment is applied at the start of the next wave, never mid-wave.
