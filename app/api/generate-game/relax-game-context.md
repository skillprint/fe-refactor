# Relax Game Context

When generating a game targeted at the "Relax" mood, you MUST adhere to the following guidelines:
1. **Pacing and Speed**: The game must be inherently slow-paced and forgiving. There should be no strict time limits or rapidly moving obstacles that induce stress.
2. **Visuals and Theme**: Use soothing color palettes (e.g., pastels, deep blues, soft greens) and smooth, gentle animations. Avoid flashing lights or jarring transitions.
3. **Audio (implied)**: If audio were possible, it would be calm. Translate this into visual feedback—soft ripples, fading particles, etc.
4. **Failure State**: The game should rarely have a harsh "Game Over" state. It's better to allow the player to try again without penalty or simply let them continue exploring or playing indefinitely.
5. **Mechanics**: Focus on matching, sorting, gentle physics, clicking to bloom/reveal, sweeping motions, or endless runners with no fail state (just points for collecting).
