# Focus Game Context

When generating a game targeted at the "Focus" mood, you MUST adhere to the following guidelines:
1. **Engagement**: The game needs to demand the player's attention through continuous, steady action or intricate problem-solving.
2. **Distraction-Free**: The UI should be minimal. Avoid clutter or unnecessary visual noise that detracts from the core gameplay loop.
3. **Feedback Loop**: Provide immediate, clear feedback for actions. Correct actions should be rewarded visually (e.g., satisfying combo counters, neat snapping animations). 
4. **Pacing**: The pacing can increase gradually to induce flow state, but it shouldn't be erratic or unpredictable. Players should be able to get into a "groove".
5. **Mechanics**: Focus on pattern recognition, timing, precision aiming, typing, continuous tracking, or complex puzzle solving requiring sustained attention.
